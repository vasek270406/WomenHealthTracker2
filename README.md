# WomenHealthTracker2 — приложение для женского здоровья

## 📱 О проекте

WomenHealthTracker2 — Android-приложение для отслеживания менструального цикла и мониторинга женского здоровья. Приложение помогает пользователям вести календарь цикла, записывать симптомы и отслеживать изменения самочувствия.

## ✨ Основные возможности

- 📅 Календарь менструального цикла и история циклов
- 🌸 Прогнозирование менструации и овуляции
- 📝 Отслеживание симптомов и самочувствия
- 📊 Статистика и анализ данных о цикле
- 🔔 Напоминания и уведомления
- 🤰 Дополнительные режимы отслеживания беременности и менопаузы

## 🛠 Используемые технологии

- **Платформа:** Android
- **Система сборки:** Gradle
- **Сервисы:** Firebase

## 📂 Структура проекта

- `app/` — исходный код Android-приложения
- `gradle/` — файлы конфигурации системы сборки

## 🚀 Как запустить проект

1. Склонируйте репозиторий или скачайте его архив.
2. Откройте проект в Android Studio.
3. Настройте необходимые параметры Firebase.
4. Дождитесь завершения синхронизации Gradle.
5. Соберите и запустите приложение на Android-устройстве или эмуляторе.

## 📚 Документация

В репозитории доступны дополнительные материалы по настройке и сборке проекта.

## ⚠️ Важно

Прогнозы менструального цикла и овуляции носят информационный характер и не заменяют консультацию медицинского специалиста.

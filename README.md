# WomenHealthTracker2

## О проекте

WomenHealthTracker2 — Android-приложение для отслеживания менструального цикла и контроля женского здоровья.

Приложение позволяет вести календарь цикла, отмечать симптомы, следить за изменениями самочувствия и просматривать статистику. Также предусмотрены дополнительные режимы для отслеживания беременности и менопаузы.

## Основные возможности

- Календарь менструального цикла и история циклов
- Прогнозирование следующих менструаций и овуляции
- Запись симптомов и изменений самочувствия
- Просмотр статистики по циклам
- Напоминания о важных событиях
- Дополнительные режимы для беременности и менопаузы

## Технологии

- Android
- Gradle
- Firebase

## Запуск проекта

Для запуска проекта необходимо скачать репозиторий, открыть его в Android Studio и дождаться синхронизации Gradle. Перед запуском может потребоваться настройка Firebase в соответствии с конфигурацией проекта.

## Назначение

Проект создан для того, чтобы упростить отслеживание менструального цикла и помочь пользователям лучше понимать изменения своего организма.

Прогнозы в приложении носят информационный характер и не заменяют консультацию врача.
